# 💱 Currency Converter App
 
Currency Converter is a Salesforce Lightning Web Components (LWC) application that enables users to convert currency values using predefined exchange rates stored in static resources. The application provides a responsive and user-friendly interface built with Salesforce Lightning Design System (SLDS).
 
## Features
 
- Convert amounts between multiple currencies
- Responsive user interface using SLDS
- Exchange rates stored and managed through Static Resources
- Modular Lightning Web Components
- Real-time calculation based on selected currencies
- Deployed on Experience Cloud for user accessibility

## Project Architecture
 
- **LWC Components** for UI and user interactions
- **Service Components** for conversion logic
- **Static Resources** for currency exchange rate data
- **Experience Cloud** for deployment and accessibility
